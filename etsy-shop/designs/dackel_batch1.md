# Batch 1: "Dackel & Teckel" Christmas line (10 concepts)

House style: use this for every design so the shop looks like one artist.
- **Medium:** loose ink line + gouache texture, visible brush grain.
- **Palette:** deep red `#A8322D`, fir green `#2F5D50`, mustard `#D9A441`, warm brown `#7A4A2A`, cream background `#F4ECDD`.
- **Character:** one recurring smooth-haired brown dachshund with a white chest patch, drawn the same way every time. This is your "mascot"; name it (e.g. *Fritz*).
- **Text:** hand-lettered or a serif display font. Add the text yourself in the editor. Never let the image tool render text.

Base prompt suffix (append to each):
`loose ink and gouache illustration, vintage children's book style, limited palette of deep red, fir green, mustard and warm brown, plain cream background, centered, no text, no watermark`

Before publishing: search each text line on EUIPO eSearch + INPI (classes 21 and 25).
Common puns like "Frohe Wauchnachten" are widely used and probably fine, but check anyway.

## Order of work
1. Generate **#1, #3, #4, #9** first. They're mugs and sweatshirts, the best-sellers, in both German and French.
2. Pick one that turned out well and order it as your sample (mug), to judge print colours against the palette.
3. Then do #2, #5, #7, #8, #10 for the Christmas collection. Publish by ~10 November.
